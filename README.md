# Sicnote

A narrative RPG / rhythm / fighting hybrid about autonomy — over your actions, and over your own
mind. In a world where every person is a musical note, a hidden class of "gifted" notes secretly
controls everyone else's decisions through an invisible power called tyrannical hypnosis. Misa, a
fast and independent 64th note, stumbles onto the secret and scribes a forbidden protective sigil
onto her own back to fight back — one that saves her from mind control while slowly killing her.

Built in **Godot 4.7 / GDScript**, PC only. Early stage: the first vertical slice is playable —
splash, a main menu you spin with the mouse, a small 3D area, an encounter, a 2D rhythm fight
scored to a 90% accuracy threshold, and dialogue where each character speaks in their own
musical note. Art is placeholder and all audio is synthesized in code.

Run it from the Godot editor (`F5`) — the main scene is `scenes/ui/splash_screen.tscn`.
Fight controls are `D` `F` `J` `K`.
